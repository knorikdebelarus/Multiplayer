# Тестирование Multiplayer Resync для RimWorld 1.7

> Экспериментальная сборка. Используйте отдельное тестовое сохранение.
> Это не стабильный релиз, не устанавливайте поверх рабочей мод-сборки без копии.

## Что нужно

- Два компьютера и два игрока со Steam (или две отдельные игровые установки,
  которые позволяют проверить подключение между ними).
- Одинаковая версия **RimWorld 1.7**, включая номер билда/ревизию.
- Одинаковый набор DLC, порядок загрузки модов и их версии.
- Harmony 3, совместимая с 1.7.
- **Один и тот же ZIP сборки нашего форка** на обоих компьютерах.

## Установка

1. Откройте GitHub Actions в этом репозитории и найдите успешный запуск
   `Validate Pull Request` для нужного коммита.
2. В `Artifacts` скачайте **комбинированный** пакет `Multiplayer-mod-pr...`,
   если он доступен. Внутри должен быть каталог `Multiplayer` с `About`,
   `LoadFolders.xml` и каталогом `1.7`.
3. Скопируйте этот каталог как отдельный локальный мод:
   `<папка RimWorld>\Mods\MultiplayerResync\`.
   Итоговый путь должен содержать
   `Mods\MultiplayerResync\About\About.xml`.
4. Отключите оригинальный Multiplayer из Steam Workshop, если он активен.
   Одновременно запускать оригинальный мод и наш форк нельзя: у обоих один
   `packageId`, необходимый для совместимости с экосистемой Multiplayer.
5. Активируйте Harmony и наш локальный мод. Для первого теста отключите прочие
   модификации, кроме игры и DLC.

## Первый тест: одна колония

1. Запустите игру на обоих компьютерах, сравните номер версии игры.
2. В настройках Multiplayer на **обоих** ПК включите
   `Experimental map-state fingerprints (both players)`.
   По умолчанию настройка выключена.
3. Создайте отдельное тестовое сохранение; не используйте основную колонию.
4. Игрок 1 поднимает сессию, игрок 2 подключается через Steam.
5. Играйте 20–30 минут на нормальной скорости, отдавайте приказы, стройте,
   перемещайте ресурсы, меняйте рабочие приоритеты.
6. Проверьте паузу, сохранение, корректное отключение и повторное подключение.
7. Повторите с 10–20 предварительно проверенными модами, затем с более
   крупной сборкой. Изменяйте по возможности один фактор за раз.

## При проблемах

Сохраните **с обоих ПК**:

- `Player.log`;
- последние ZIP-файлы в каталоге `MpDesyncs` (если появились);
- `Config/ModsConfig.xml`;
- точную версию RimWorld и SHA/номер использованного билда форка;
- какой игрок был хостом, на каком игровом тике появилась проблема,
  что делали перед ошибкой;
- наличие ошибок подключения/вылетов и приблизительное влияние на TPS.

На Windows каталог данных обычно находится по адресу:
`%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\`.

Для тестирования не нужно присылать Steam-пароли или секретные ключи.
Просмотрите логи перед отправкой: они могут содержать имена пользователей
и локальные пути.

## Ограничения этой версии

- Детектор сравнивает **только часть состояния** объектов на карте
  (ID, тип, координаты, стопка, HP).
- Он не определяет автоматически, какой конкретно мод вызвал расхождение.
- Снимки делаются раз в 600 глобальных игровых тиков.
- При пропущенном снимке сравнение этого тика не выполняется.
- Пакетный сетевой протокол форка: **157**; старый Multiplayer несовместим.
- Восстановление после desync не автоматизировано; продолжение после ошибки
  без повторной загрузки безопасным не считается.
